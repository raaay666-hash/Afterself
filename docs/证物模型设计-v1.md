# 《启动阶段》证物模型设计 v1

日期：2026-09-30。已制作 49 个独立 2D 展示模型（37 核心条目＋12 人物收藏页），不是 3D 网格，也未接入正式游戏。

沿用本项目粗像素、少色平涂风格。模型分为真实物件／文书造型、数字记录的案卷展示代理、同源附件的纪念索引。证词不被擅自改为录音实物；技术记录图不表示侦探把终端机器收进背包。新增装订、外观磨损和配色属于造型提案，不单独证明剧情事实。

## 素材规格

- 全批共用 16 色，透明背景，无抗锯齿、阴影模糊和随机材质噪点。
- 每件：48×48 收集图标；80×56 原生正面／第二视图；160×112 整数倍检查图。
- 每件包含独立 SVG 与 model.json 几何源，可修改形状、颜色、热点，不依赖图像生成接口。
- 第二视图按物件分别采用背面、展开页、附件或来源链，不能一律把信息放在背面。
- 关键姓名、时间、编号与原话由游戏文字层叠加。图上的短线仅是排版示意，不是可读文字或新的事实。
- icon、front、secondary 三张图无自动剧透锁；接入时必须由真实剧情事件控制解锁。manifest 中 spoiler_gate 是建议键，不是已存在的运行接口。
- 检查热点是 160×112 坐标下的初版范围，正式 UI 需按实际显示比例转换。

## 交付文件

- assets/evidence-models-v1/<条目 ID>/：每件全部素材与几何源。
- assets/evidence-models-v1/manifest.json：索引、来源关联、造型说明、热点与文件路径。
- assets/evidence-models-v1/inventory-atlas.png：10 列、5 行、48px 格；末格透明。
- assets/evidence-models-v1/previews/：六章图和全量总览。
- assets/evidence-models-v1/gallery.html：离线逐件看正面／第二视图，显示说明与热点。
- scripts/build_evidence_models.py：可重新生成模型、预览、索引和分发包。

## 同源关联与状态变化

孟岚的空白询问栏关联 c3.medical；顾舟空页和小满的信关联 c5.names。分别制作展示素材，不把它们算成额外独立证据。所有背面／附件都是检查视图，不暗示副本能独立印证原件。

模型只含初见正面和第二检查视图。已核实、封存、归还由 UI 标记叠加，避免盖章把原文盖掉。闻遥的钟不做时间随机动画；上传表两格初始均留白，选择之后才由真实事件添加状态。

## 接入建议与验证范围

使用 TextureRect／Sprite2D 时设为 nearest，检查图优先整数倍缩放；原件正文与热点标签使用既有 Fusion Pixel 字体。SVG 是编辑源，PNG 是交付素材。数字记录的代理图只出现在案卷，场景不随意新增设备。

生成检查包括：49 条目覆盖、全路径存在、尺寸、透明边界、16 色范围、正反差异、图标不重复、SVG 整数坐标与热点坐标。另在离线浏览器检查切换与窄屏显示。检查结果记录在 validation.json。没有替换现有美术，没有修改玩家存档，尚未验证游戏内热点手感。
