# 证物模型 v2 · 粗像素重绘

日期：2026-09-30。用户指出 v1 不符合整体美术，本版逐件重画 49 个模型；v1 保留为被否定的旧稿。没有修改正式游戏。

## 本次修正

- 原生网格从 80×56 改为 32×32，直接从新几何画出，没有缩小旧 PNG 冒充重绘。
- 使用 scripts/pixel_skin.gd 中完全相同的 20 色母调色板，单件限制在 10 色以内。
- 粗轮廓、阶梯边缘、不对称折角、2px 主块。减少文书细线和均匀黑框，让色块体积优先。
- 原生图标 32×32，收集栏显示图 64×64；检查图 192×192，都是整数倍最近邻。
- 每件独立正面与第二视图、PNG、SVG、几何 JSON、检查热点。
- 关键文字仍放在可读的 UI 正文层，像素图不编造时间、签名或真实文字。

## 对照依据

检查了 build/v6/apartment.png 的实际游戏截图、scripts/pixel_skin.gd 的调色板与 docs/人物动作修复-v0.3.md 的粗颗粒约束。对照图只是美术审阅合成，不是正式游戏已接入截图。审美是否匹配仍由用户判断，文件检查不能替代该判断。

## 来源与剧情边界

数字记录模型仍是案卷展示代理，不表示从现场带走机器。c3.blank、c5.empty、c5.letter 保留原有同源关联，不额外计为独立证据。闻遥钟的指针为造型示意，不能当作已经设定的停表时间。上传表初始选择均为空。
