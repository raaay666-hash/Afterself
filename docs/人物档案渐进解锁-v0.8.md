# 人物档案渐进解锁 / 0.8.0

## 规则

档案共十二个位置。林砚从开局可见；其他角色在剧情对白中开口，或玩家进入其所在场景后，卡片才会点亮。锁定卡不显示姓名、外形与介绍。初识卡仅显示姓名和当前可确认的身份；点击后读取已知记录。

记录逐条增加，不覆盖旧记录。新内容取自已核实的证据、已听过的个人陈述、对质和章末情节，而非仅按章节号一次放出。例如：宋屿先只有三天记忆缺口，第一章告知真相后才追加现行身份；邵为在执行证据与对质前只显示夜班职责；闻遥的旧备份经历要听她亲口说完才补入；银发董事在第三章衔接完成前不显示真实姓名。人物卡会随进度重新计算，回访旧章节不撤销已经认识的人。

询问菜单使用当下可知的身份简介。普通暂停菜单不再提供可提前浏览全员姓名的开发骨骼页。

## 存档

相遇人物 ID 保存在 `campaign-v6.json` 的 `cast_met` 列表中。读取时仅接受 0 至 11 的整数并去重；介绍阶段仍从已有证据、选择与章节状态计算。旧存档没有此字段时，从已完成首章、已看过的对白、现场原件、当前场景及已完成章节恢复可以确认的相遇；无法证明的旧现场访问保持锁定，重新遇见时点亮。旧存档文件不写回。

存档文件名和其余剧情版本保持不变：`chapter1-v6.json`、`campaign-v6.json`。
