# 0.1.0 验证记录

日期：2026-09-29。环境：本机 Windows x64；Godot 4.5.1 stable official f62fdbde1；OpenGL Compatibility；NVIDIA GeForce RTX 5070 Ti Laptop GPU。

## 已通过

1. 三个场景交互可获取全部七份证据，重复收集不重复计数。
2. 缺证、错误理论或不匹配的证据均无法通过结案。三步正确推理可到达身份报告，两种结尾均可达。
3. 存档写入磁盘、替换原文件、重新解析后还原完整结案状态；损坏类型、重复线索与非法章节不能错误解锁结尾。验证使用独立测试存档，不覆盖玩家实际存档。
4. 十二个人物各有 23 个真实 Bone2D 节点。站立、行走、说话、思考、取证动作旋转值均有效。
5. 行走相位多点采样，腿部 IK 的脚踝目标误差小于 0.05 局部单位。角色实际平移时支撑脚在世界坐标中的滑移小于 0.05 单位，能准确到达行走目标并恢复站姿。
6. 三个可达手部目标误差小于 0.05 局部单位；极远目标被限制，不产生无效旋转。
7. 在真实图形窗口内注入鼠标事件，验证标题开始、场景切换、物件收集、证据查看与关闭、实验室打开、行走按钮、骨架开关、转身，以及点击位置到手部末端的映射。手部末端与点击屏幕位置误差小于 0.25 像素。
8. 从官方模板导出单文件 Windows exe；在导出的 exe 中运行完整逻辑、磁盘存档和骨骼验证，退出码为 0。引擎模板从官方多平台 ZIP 按 HTTP Range 提取，只下载 Windows x64 release 部分，解压后核对 ZIP CRC32。
9. 导出后的 exe 也通过真实图形窗口鼠标事件验证。由该 exe 保存场景、动作实验室和十二人设定截图，进行视觉检查。

## 检查中发现并修复

- 初始站姿过度屈膝：提高骨盆并重算步幅与腿部可达范围。
- 骨骼线被部件遮住、场景人物透过模态框：分别修正绘制层级。
- 手部目标读取系统鼠标位置导致人工注入点击偏差：改用控件收到的事件坐标转换，加入屏幕落点测试。
- 十二人设定页的中文长句超出卡片宽度：调整 Label 自动换行与尺寸初始化顺序，并启用边界裁切后重新截图检查。
- 动作回调中同名变量导致 GDScript 解析失败：改名后重新运行全部检查。
- 沙盒禁止创建 Godot 用户日志目录时引擎异常退出：使用正常 Windows 权限进行实际运行验证；未修改系统配置。
- 受限环境下的截图运行记录了一条系统根证书读取提示；样机不使用网络，画面输出和退出成功。正常权限下的图形验证日志没有该提示。

## 未验证或尚未制作

没有在其他电脑、不同显卡和所有 Windows 缩放比例上验证。没有陌生玩家时长测试；不宣称样机已有三小时或完整第一章三十分钟内容。连续动作的艺术质量、起停缓动、复杂转身过渡、脚步声、表情口型、人物专属动作及最终分层像素贴图尚待进一步制作与人工验收。

静态造型参考由内置 imagegen 生成，完整提示词随项目保存；并未把它冒充已经完成的骨骼素材。
