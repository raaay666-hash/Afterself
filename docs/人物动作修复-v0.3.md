# 人物与动作修复 v0.3 设计及问题排查

## 已确认的问题

1. 图集并非严格等分网格。旧读取器用宽高整除切格：主角头部少了 11 像素高度，上衣被截短约 41 像素，前臂和手掌区域混入上一排残片，NPC 头部混入下一排衣服。
2. 换肤时将全部旧 Polygon2D 隐藏，包括没有新贴图替代的脖子。头部按包围盒缩放、没有用下颈连接点定位，导致漂浮。
3. 手掌每帧被强制旋转至世界水平，掌面与前臂方向不一致；两侧前后层次也欠清楚。
4. 站姿骨盆 -27.7、行走 -24.2，起步立即下沉 3.5 局部单位。步幅与抬脚过大，速度瞬间开启/停止。手臂摆动相位没有与同侧腿反向匹配。
5. 原测试验证 IK 数值，却未验证贴图区域、颈部连接和连续姿态；静态场景截图不能验收走路。

## 本次修改方案

- 按高不透明度连通部件确定每块实际图集范围，不重绘场景；部件保持原始宽高比与准确关节枢轴。
- 调整头身比例，设置显式下颈连接点，恢复可见颈部并由衣领压住接缝。
- 增加两个有效腕关节，从 23 到 25 骨骼；手掌随前臂，再做有限腕部旋转，道具单独保持朝向。
- 缩短步幅与抬脚，平滑骨盆高度、速度和起停；同侧手脚反向摆动，持物手采用较小摆幅。
- 新增独立模型检视图、行走连续帧和动画预览；检查前后朝向、静止、行走、交谈和取证。
- 用导出 EXE 验证视觉与完整章节，发布独立 v0.3 包；继续兼容 v2 存档，不覆盖旧包。

## 用户风格纠正后的最终方案（2026-09-30）

用户再次指出身体、脖子不自然，并明确选定《暗面侦探》式粗颗粒、大色块、简化五官和少量颜色。中途生成的细腻插画式上身没有采用，也不进入发布包。

最终首章五人使用 `assets/characters/upperbody-pixel-final-v3.png`。这是内置 imagegen 生成并针对短颈、无袖片作定向编辑的连体头颈上身图；提示词完整保存在 `docs/粗像素人物提示词-v3.txt`。原始 PNG 没有被脚本重绘或裁成新图片。图集区域由 `assets/rig-atlas-v3.json` 标定。

`scripts/pixel_skin.gd` 将头、颈、衣领、躯干作为同一连续网格，分配到 head、neck、chest 的骨骼权重，不再用三张独立精灵拼接脖子。材质将上身映射到共享 20 色调色板，四肢采用少色的骨骼多边形。每名人物在 80×80 透明画布绘制后最近邻放大，实际身体约 55 像素高。站立截图中每人不透明像素实际使用 15–20 种颜色。背景按 320×180 取样显示，中文字保持原分辨率。

保留手脚解析 IK，新增左右 wrist 两个真实 Bone2D，共 25 个关节。手掌跟随前臂，道具独立稳定朝向；步幅周期 24 局部单位、抬脚最高 3.2 单位。速度做加减速，髋部按双腿可达距离求解，起停姿态逐渐混合，抬手目标有过渡。脚步声音从足部接触相位触发，不再按固定计时器播放。

## 剩余边界

造型与走路观感仍需用户试玩确认；数值检查通过不能证明审美满意。转身仍是镜像，没有独立侧转身帧。首章五人采用新上身，开发附录中的其他七人仍使用旧来源资产经过粗像素渲染。其他五章没有在这次人物修复中实现。
