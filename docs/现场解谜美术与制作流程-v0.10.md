# 现场解谜美术与制作流程 · 0.10

设计日期：2026-10-01。以《现场解谜流程设计-v1》为叙事依据。以下规范已写入 0.10；运行与视觉验证结果见《现场解谜验证-v0.10》。十二段主线共 23 步，六段可选各 1 步，总计 29 步操作。

## 美术规格

不替换已有场景与角色。局部操作台使用程序绘制的可编辑像素图形，原生 180×76 网格，放大四倍，边缘不抗锯齿。点击对象覆盖清晰的 20px 字体，正文 24px。鼠标与键盘操作都不依赖辨认单个像素。

现场门使用 56×96 网格并放大四倍：维修走廊门框对齐背景中的原门口，另设可点击的上部铭牌；B 巷账房复用门模型。以暗青阴影、少量旧漆剥落、铰链和门灯表示材质及开合，完成后现场仍保留状态。第一章“现场操作”位于底部导航，避开中央交互说明。

统一材质色：墨绿 #172c28、暗背景 #0d191b、纸白 #d0c3a0、纸影 #96866c、黄铜 #b89860、旧铜 #82624a、警示赭红 #a76c57、信号绿 #8ba987。光亮代表状态变化，旁边同时写状态文字；不靠红绿辨认结果。

所有近景分成实物台、规则与来源、操作反馈三部分。实物台在左，操作说明在右；底部有核验、提示、原件回查和返回。当前阶段上方明确显示，成功后的下一目标保持可见。已完成的阶段可回看，回看不重写报告。

## 具体接入

第一章抽屉热点进入日期锁，维修走廊签收簿入口先进入维修门；开门只给巡检权限。恢复终端以工单调阅材料，四时点与保管区间统一在新核验台操作。

第二章账簿入口进入地图定位与路径，模板记录入口进入套版查询。第三章批处理与反对书入口先按目录调阅，再操作纸带与来源链。第四章教学原文入口先拼接抄本，仪表与适用情境在共同计量台操作。第五章调试口入口先排障，再装模块、定位遮罩、读取短语；解开不会自动发送私人资料。第六章票据入口检查当期身份，会议附件入口进行两端对照与证据包装。

后五章原有“现场推演”按钮进入本章两段流程；案卷的“现场核验”也导向同一进度。旧式分类与管线不再要求玩家重复做。既有章内答案、核验封存仍保存，以保留剧情和旧存档验证。

六件小谜题从现场操作目录进入，有材料或明确人物叙述才开放；完成只追加人物侧记。人物物件系统继续保留，不制造新收集数量。

使用 chapter1-v10.json 与 campaign-v10.json；首次可回读 v9、v6、v5、v4。旧文件不写回。旧版已开始对质、已结案进度免于新增门槛；新内容允许回访。旧版取得的证物不会消失，也不会把免于门槛冒充已玩过新谜题。
