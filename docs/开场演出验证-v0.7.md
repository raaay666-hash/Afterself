# 开场演出版 0.7.0 / 验证记录

日期：2026-09-30。Windows x64，Godot 4.5.1。

## 验证

- 新游戏先显示四幕开场，跳过后进入第一章原有到场对白；窗口操作检查覆盖“下一幕”三次、“进入调查”和“跳过开场”，导出 EXE 共 12 项检查通过。
- 导出 EXE 的首章与动作、剧情、存档回归共 176 项通过，包含开场中断后重播，以及到场对白中断后续接。
- 源项目从标题经第一章走到第六章私人结尾的窗口自动流程共 685 条通过记录；测试通过鼠标与键盘操作，未测量真人游玩时长。
- 四幕截图在 `build/v7/opening.png`、`opening-2.png`、`opening-3.png`、`opening-4.png`，已检查中文可读性、布局与剧情信息；背景是现有像素场景缓慢移动，文字淡入。
- 测试进程将 APPDATA 指向项目内临时目录。玩家原有 `%APPDATA%/StartupPhase/` 存档未用于测试。旧 0.6 ZIP 的 SHA256 仍为 `1eb4e8ff22ca6164f53a179ac5436be98f01f4c1e2899bf9a1b1da5af81ce4e0`。

Godot 在此环境报告系统根证书库读取错误；游戏离线运行，窗口与导出测试仍通过。尚无陌生玩家对开场节奏的主观验收，也未做跨设备 Windows 验收。
