## 整合内容

当前源工程重新导出：六章一周目、12 名人物、49 件证物、12 段主线现场操作、6 段可选小谜题，共 29 步操作，包含人物档案、物件委托、证物检查、故事复盘与公共／个人结局。

保留九张场景、最终粗像素证物、角色少色上身与共享骨骼动作、中文像素字体和七类程序合成声音。内嵌资源包 429 个文件，逐项 MD5 校验通过；49 件证物对应 147 张最终图片和 150 个检查热点。全部六章运行 JSON 与九张背景确认收录，旧版证物、图库预览、设计文档、安装器原型与打包源码不进入游戏包。

安装器沿用已确认的 AFTERSELF 标题、档案室背景、林砚及图标原图，增加真实解包、逐文件 SHA-256、真实写入进度、目录选择、快捷方式、完成后启动和卸载。图标只转换编码与尺寸，原 PNG 哈希保持已选记录一致。游戏内部名称及 `%APPDATA%/StartupPhase/` 存档目录保留。

试玩说明与 Godot／字体完整第三方许可在安装前的可滚动窗口中提供，安装按钮由阅读确认勾选启用，没有杜撰游戏商业许可协议。

## 安装、卸载和已验证边界

默认安装到 `%LOCALAPPDATA%/Programs/Afterself`，可选择本机空目录。首次发行不执行覆盖升级；若目标已有文件，要求改选空目录或先卸载旧版。安装取消或失败只清理本次创建的文件。卸载只删除清单内未修改的文件，不递归清空安装目录；AppData 存档、修改过的文件和自行添加的文件保留。快捷方式只有仍指向本安装位置才删除。

QA 使用隔离快捷方式目录，没有写入用户桌面或读取玩家存档，也没有登记 Windows HKCU 卸载项。因此 Windows“已安装的应用”中的登记和卸载入口虽然已实现，尚未通过该实际入口验收。默认桌面位置、开始菜单位置与安装结束自动启动也没有在用户日常环境中执行。

没有在其他电脑验证 Windows 兼容性，没有陌生玩家节奏／难度／三小时时长或主观听感验收。没有配音，二周目未制作，发行文件未签名。游戏日志中的 Windows 根证书读取告警来自受限环境；本作离线运行，最终检查依据明确通过标记和零退出码。

## 可复现构建

入口为 `scripts/build_first_release.py`，图标编码转换为 `scripts/export_afterself_icon.py afterself-approved-installer-art`。安装器源码在 `installer/AfterselfSetup.cs`，真实权限声明在 `installer/app.manifest`。本机 Godot、Windows .NET Framework 编译器和 Python 供开发使用，玩家无需安装开发工具。

`scripts/check_release.py --exe build/first-installer/stage/StartupPhase.exe --out build/first-installer/qa-final` 检查游戏逻辑，加 `--window` 检查实际窗口流程；`scripts/verify_evidence_release.py` 检查最新内嵌资源。验收脚本现将输出目录转为绝对路径，避免相对日志路径与测试工作目录错配。
