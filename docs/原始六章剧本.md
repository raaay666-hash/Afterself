# 《启动阶段》三小时剧本定稿（第一版）

## 一、作品定位

类型：2D 像素点选侦探游戏。首次通关目标约三小时，六章，每章有一桩能够独立结案的案件。气质是黑色幽默、诡异、冷峻，偶尔温情。案件与人物推动哲学问题，不用长篇设定说明替代调查。

**一句话卖点：**一名27岁的数字侦探查出自己所在的城市原本是一款游戏；他必须联系现实中80岁的自己，阻止公司替整座已发展出文明的城市决定命运。

**主题：**复制出来的人能拥有独立的人生；创造者、原型和后来的副本，都不能永久替另一个人作决定。

暂定游戏名《启动阶段》。其含义在结尾改变：肉体人生可能只是数字人生的开端，玩家经历的整部游戏也可能只是下一段人生的开端。

## 二、不可变更的世界规则

1. **上传是复制。**现实中的意识不会因扫描而离开身体。27岁的林砚上传后，现实林砚继续活到80岁；数字林砚从27岁快照开始独立生活。结尾不证明原人的主观体验能否延续。
2. **恢复不是复活。**运行中的人格被终止后，从旧备份启动的是另一个实例。他可能拥有相同记忆，但没有被终止之后的经历。任何角色都不能用“反正有备份”轻描淡写地撤销死亡。
3. **时间可以调速，不可倒流。**公司曾累计开启约37小时高倍速，每现实小时约等于数字世界一千年；其余时期以常速运行或暂停。数字文明因此有约三万七千年的历史，而现实只过去53年。高倍速消耗巨大，不能在游戏中无限使用。
4. **记忆清理是可操作的制度。**部分长期运行的居民接受过自愿清理；公司后来扩大为未经当事人逐次同意的批量清理。清理过的内容可能保存在档案中，但读取档案不等于恢复原来的连续体验。
5. **数字世界不是空壳。**最初有公司技术员与测试者的真实人格副本，后来有新加入的上传者、从备份独立发展的实例以及在当地成长起来的新居民。他们建立家庭、组织、法律和历史；没有人是可随意重置的背景角色。
6. **对外通信有边界。**游戏世界长期与公共上传网络隔离，只能通过审查后的维护通道传递摘要。第五章的“突破次元”是找到旧调试通道，把可验证的证据送到现实，而非施展超自然能力。双向交谈时双方暂时调为相近速度。

## 三、人物与关系

**数字林砚（玩家主角）：**外表27岁，异常案件调查员。他的档案链可追溯到三万七千年前，但现行实例只记得最近的人生。他想救城市，也必须面对旧版本曾支持过强制清理。玩家不能用“我以前同意过”替今天的他作决定。

**现实林砚（第二视角）：**80岁，公司高管，曾是游戏技术员。27岁时自愿上传测试快照。年轻时见过早期居民表现出独立意志的证据，却接受了公司的隔离方案。如今公共死后上传服务与旧项目共享底层设施；他有权投票，却不能毫无代价地拔掉电源。

**闻遥：**第一章协助查恢复记录的档案员。她自己也曾在多年前被终止、由旧备份重新启动，因此格外在意现行实例的权利；这一经历在第三章才告诉林砚。她不替已死的旧实例签字，之后持续协助整理证据。

**孟岚：**数字城的记忆医师。曾用自愿清理救过病人，也发现公司把治疗扩成了便于管理的常规程序。她能解释技术与伦理，但隐瞒自己曾签署一次错误授权。

**周临：**现实公司的运营负责人。推动隔离旧世界，担心它的自治诉求危及公共上传服务。他伪造的不是全部证据，而是“全体居民同意”的代表性数据；他的顾虑有现实基础，手段却不可接受。

**顾舟：**数字城维修员，负责旧调试接口。表面上用荒诞口吻抱怨“神谕其实是工单”，私下保存了几千年间被删除居民的名字。

## 四、三条叙事线的揭示顺序

- **数字线，占主要游玩时间：**林砚查案，玩家点选场景、盘问证人、组合证据。
- **现实线，占少量短场景：**从第二章开始操作80岁的高管，查文件与作决策。镜头先不公布他与侦探同名的意义，第三章明确揭示。
- **过去线，仅用可调查记录和一小段可玩回忆：**展示27岁的技术员如何启动测试，不另做一套完整玩法。

数字线发生在维护前的数日；现实线发生在董事会表决前的一个下午。两线的交谈只在第五章的同步窗口发生。

## 五、六章可玩剧本

### 第一章《睡过头的人》｜约30分钟

**开场：**一位妻子报案：丈夫昨夜睡了九小时，今早照常起床，却不记得他们上周和好的事。邻居坚持昨夜见过担架，公寓管理处否认有人死亡。

**调查：**公寓、走廊、档案室三个场景。玩家检查杯垫上的约会日期、夜间维修单、门禁记录；盘问妻子、邻居、维护员和“今天的丈夫”。维修单编号能查出紧急恢复登记。丈夫的旧便条则证明昨天的他发现了管理处违规清理记录。

**结案：**维护员为掩盖记录终止了昨夜的丈夫，再启动三天前的备份。玩家用维修权限与恢复时间指认他。现行丈夫并非凶手，也不是死者回来了。

**首次反转：**报告要求选择死者与现行者的法律身份。界面露出“实例”字段；林砚看向窗外，发现城市地平线之外是尚未加载的灰色区域。玩家确认这是一座数字城市，而非普通失忆案。

**总线索：**被隐藏的清理名单上有林砚的编号。幽默落点是管理处坚持“死亡与到岗并不冲突”，温情落点是妻子仍愿意听现行丈夫讲自己的想法。

### 第二章《没有玩家的游戏》｜约25分钟

**独立案件：**旧城区将被拆除，一群居民拿着几千年的房契抗议。管理处称那里只是废弃游戏关卡，住户是临时程序。玩家查地契、旧地图与被重复使用的场景道具，发现确实有两名居民伪造最新产权，但城里大多数家族在废弃之后仍连续生活了数千年。

**总线索：**旧地图标着真实公司的项目代号；维护记录显示高倍速测试的累计时长。现实线第一次出现：80岁林砚收到关于“旧项目异常人口”的董事会简报。

### 第三章《同一个凶手》｜约30分钟

**独立案件：**多桩相隔数百年的清理案都留下林砚的签名。玩家调查签名的生成方式，发现其中一份确由旧林砚授权，一份被公司套用了旧授权，一份是另一独立实例写下的反对意见。不能把它们当成同一个人的一致决定。

**中期反转：**林砚查到原始上传记录：27岁的技术员林砚把自己复制进公司游戏；现实中的他继续生活，如今80岁。数字林砚所属的实例链跨越约三万七千年，现行的他并未连续记住这一切。现实线展示80岁林砚看到侦探影像。

### 第四章《神谕版权案》｜约25分钟

**独立案件：**两座城为一份“造物主指令”争夺水源分配权。玩家查出文本原是技术员写的教学任务，后来被一方截去条件，成为维系数千年的法律。结案要指出伪造与真实历史，而非替两城决定谁配拥有水。

**总线索：**数字居民已建立自己的制度，并非等待现实人类指示的角色。现实线查出公共死后上传服务与旧游戏共享存储和备份基础设施；立即关停旧项目会造成连带损失。

### 第五章《越界来信》｜约30分钟

**独立案件：**数名维修员因“神迹般”的画面冻结被指控破坏城市。玩家查出冻结由旧调试端口与公司审查程序冲突引起；其中一名维修员确曾借故删除证据，但其他人是被嫁祸。顾舟交出多年保存的被删除者名册。

**交汇：**数字林砚利用案件中找到的端口，把签名证据、人口史和一条私人消息送出。现实林砚认出27岁时只有自己知道的密钥。两人以同步速度交谈。现实林砚说“我是你”，数字林砚答：“你是我的童年。我的孩子已经死去四千年，你连她的名字都不知道。”

**终局反转：**数字林砚的旧版本曾支持记忆清理，现实林砚年轻时也见过居民自主性的证据。双方都曾让制度走到今天；任何一方都不能以“原版”身份独占裁决权。

### 第六章《全体同意》｜约40分钟，含结局

**独立案件：**董事会收到数字居民的“自愿隔离”投票结果。玩家在数字线查选民名册、恢复时间和被删除的反对票；在现实线查签名算法与会议附件。最终证明周临调用旧备份重复投票，把数个年代的副本当作今日居民的授权。玩家能在表决前提交清晰、可核实的证据。

**公共抉择：**80岁林砚无法替数字城投票，但能选择自己提出的现实方案：

1. **隔离保存：**保证独立供给、停止新上传与外部连接，交还内部治理权。保住现有居民并降低外溢风险；亲友通信与迁移受限。
2. **开放连接：**公布历史，允许在双方同意下接入公共上传网络。能重建联系并扩大选择；现实与数字社会须共同承担安全和资源冲突。
3. **限期共治：**保全所有实例与清理记录，开放受监督的通信，设定期限制定新规则。减少立即损失；临时权力可能被拖成常态。

前三章是否尊重恢复实例的独立身份、第五章是否保住完整名册，会改变谁支持方案及尾声中的具体损失；不会暗藏一个唯一正确选项。

**私人尾声：**表决后不久，80岁的林砚病情恶化，来到生命末期。终端问他是否上传最终人格备份。选择“不上传”，故事结束；选择“上传”，画面在执行结果出现前切黑，然后显示“二周目已解锁／现在开始或返回标题”。此处只确认备份指令已提交，不宣称原人的主观意识得到延续。二周目的内容以后设计，一周目故事到此完整结束。

## 六、玩法、篇幅与制作边界

- 首次通关目标约180分钟。六章分别约30、25、30、25、30、40分钟；这个数字要靠陌生玩家试玩校准，不能靠阅读稿件估算为完成。
- 每章最多三个主要场景、一个核心证据组合谜题和一次结案对质。关键线索允许通过两条途径获得，防止点漏物品卡关。
- 全作约10到12个主要可进入场景，复用街道、档案室和公司会议区。现实线只需少量办公室场景；过去线主要借档案与短回忆呈现。
- 不制作实时运转的文明模拟、不允许玩家自由生成无数副本、不把三万七千年做成可漫游地图。时间的重量由历史痕迹、人物关系、案件和场景更新表达。
- 荒诞笑点来自制度与日常碰撞：死者的出勤考核、神谕的工单编号、两个“本人”争同一张会员卡。严肃抉择落到具体人物身上，避免大量抽象辩论。
- 一周目提供完整案件真相与公共结局。上传后出现的二周目入口仅是承诺未来的另一种视角，不承担解释一周目必需真相的任务。

## 七、制作前须锁定的三件事

1. 第一章的逐场景对白、可点物件、谜题依赖和结案顺序。
2. 第三章三份签名各是谁留下，证据如何让玩家独立判断。
3. 第六章三种方案在画面上各让玩家看见一项收益和一项代价。

这三处通过纸面推演后，再制作第一章约30分钟的试玩版。试玩结果可以调整节奏和对白，但不轻易改动上传、复制与时间规则。
