# 0.6 调查体验设计

保留已认可的粗颗粒场景和人物。现有问题是系统字体与像素美术脱节、通知缺乏辨识、六章操作重复。此轮将阅读、动手核验、推论、案后复盘连起来。

## 视觉

- 内置 Fusion Pixel 简体中文开源字体（v2026.09.25，OFL），小字 10px 放大为 20px，正文 12px 放大为 24px，标题用 36/48px。关闭抗锯齿，使用整数倍字格。字体许可证随发行包提供。
- 对话框采用深墨绿、米白正文、黄铜说话人签条、方角双线及页码。正文加行距；通知改为独立的归档回执条，后五章也可显示。
- 证据阅读保留浅纸深字，增加归档编号和来源标识。按钮有焦点、悬停和已选状态。

## 故事脉络

卷宗新增全篇索引：只开放真正结案章节，直接跳到第二章不伪造第一章通关。未完成的章不展示标题以外的信息。

每个结案页包含：案情摘要、四张按因果顺序排列的故事卡、三项证据支持的结论、原件回查、本次选择。玩家也可打散并自行复原故事卡；正确后标记“已梳理”，错误指出首个不相符的位置。复盘不改变主线结果。

## 六项现场操作

每章新增一项操作，在结案对质之前完成；中途操作保存，老版已开始的对质或已结案不被重新阻断。

1. 凭据与回执：交换四张时间卡，复原领取、终止、归还、启动的顺序。
2. 地图校验：对比初始地图与现状，标出用途改变的地块；不能把保持空置的地块也划为变化。
3. 授权源流：交换带年代的记录，复原旧授权、服务调用、反对意见的先后。
4. 双城计量线路：转动管线，让核验信号经过两城计量点到达复核台；这只是检测台，不替居民分配水量。
5. 只读通信线路：转动接线，依次经过镜像、同步、审计后抵达发送端；不接通写入旁路。
6. 附件比对：左右对照原始票据与摘要，标出被改写的反对、保留、历史来源字段。

时间顺序、视觉差异、空间连线三类操作共用无计时、可重置、分级提示原则。管线有实时通路反馈，错误不抹除已有线索。

新发行目录 build/v6，独立 chapter1-v6 / campaign-v6 存档；首次读取 v5 或 v4，绝不写回旧文件。新功能进度与全篇进度一同保存，载入时核对材料与完成条件。制作后检查六章流程、旧存档迁移、剧透边界、错误操作、界面截图、字体覆盖和导出程序。
