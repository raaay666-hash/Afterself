# v0.2.0 第一章可玩版 · 验证记录

日期：2026-09-29。引擎：Godot 4.5.1 stable。目标：Windows x64。旧版 EXE、ZIP 与存档保持独立。

## 完成内容

重建雨街主菜单、公寓、维修走廊和档案室画面；首章角色接入骨架分件。添加分话题询问、文书调查、日期锁、恢复时间线、证据组合、三轮对质与两个身份报告结局。补齐提示、音量、逐字显示设置、自动存档与章节收束。

本轮修复了 NPC 肩口和手臂挂点不重合、人物比例偏小、打开面板后行走继续触发交互、原生下拉框自动输入不可靠的问题。时间线改为界面内循环选择记录。

## 验证证据

- `build/v2/export-self-test.log`：导出 EXE 执行。覆盖证据前置、错误密码、三方凭据见证、时间线顺序、七份证据、无效组合、三条推论、三轮对质、两个身份结局、磁盘存档往返和坏存档校验。输出 `V2 TESTS PASSED`。
- 同一测试覆盖十二人各 23 个 Bone2D、五种动作各 80 个姿态采样、旋转有限性、步行脚踝误差小于 0.05 局部单位、校正肩口后的手部可达精度与不可达目标截断。数值通过不等于手工动画艺术验收。
- `build/v2/export-playthrough.log`：导出 EXE 的真实窗口自动通关。发送鼠标与键盘事件，保留真实行走；实际输入密码和选择时间记录，通过案卷组合三条推论，三轮对质后进入独立身份结局。另测行走中暂停、停留、恢复后到达原目标。输出 `FULL WINDOW PLAYTHROUGH PASSED`。
- `build/v2/export-capture.log` 与 `build/v2/windows/*.png`：导出程序实际渲染。检查标题、三处室内场景、中文对话、案卷布局与角色拼接。
- `build/v2/export-audio-smoke.log`：正常启动，七段音频加载；雨声与氛围播放状态均为 true，随后走正常退出清理。退出码 0，无脚本错误或资源泄漏警告。未进行听感验收。

## 音频退出修复

限制环境下的静音测试不能代替正常音频启动。补测发现直接销毁场景树会留下两个播放实例。正常退出现先停止音频，再留出音频线程释放时间，然后退出。循环终点按音频时长乘采样率计算，避免把压缩数据字节数错当采样数。

早期沙箱日志出现系统证书库、着色器缓存访问错误。正常权限下最终 EXE 的通关、骨架和音频退出测试无上述错误。旧日志保留供追溯。
