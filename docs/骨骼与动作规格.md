# 人物骨骼与动作规格 v3

## 骨骼与皮肤

root、pelvis、waist、chest、neck、head；前后各 clavicle、upperarm、forearm、wrist、hand、thigh、shin、foot、toe；prop_socket。共 6 + 9×2 + 1 = 25 个真实 Bone2D。

首章五人使用一张连贯头颈上身的加权 Polygon2D 网格，头、颈、胸的权重之和为 1。衣领和下颌之间没有独立图片边缘。四肢绑定相应骨骼，关节留覆盖量。80×80 透明画布统一产生大像素，最近邻放大。其余七人仍使用旧资产来源，不称作十二套专属美术。

## 动作约束

- 行走相位按实际距离驱动，24 局部单位为一个周期；支撑期 60%，足相对身体的速度抵消身体移动。
- 抬脚采用位置/速度连续的曲线，最大抬高 3.2 局部单位；腿长为 13 + 12，骨盆高度由两侧腿的可达距离共同限制。
- 角色速度做加减速，步行和静止姿态在 0.2 秒左右混合，避免骨盆瞬间跳变。改变目标方向先减速再镜像。
- 手臂长 11 + 10；前后各有独立腕关节。手掌跟随前臂，道具插槽单独稳定方向。不可达目标截断，不拉长肢体。
- 低分辨率脸部不做细微随机旋转，避免单像素眼睛抖动；取证保留小幅头部倾斜。
- 脚步声由跨越接触相位触发，暂停时没有脚步事件。

## 验收范围

关节有限性、手脚 IK、30/60/120 fps 下起停和到达、落脚事件、连续移动反向、真实窗口点击目标、透明截图连通性、步态逐帧图、实际移动 GIF、导出 EXE 完整章节。

步行接触期骨骼脚踝世界位移误差 < 0.05 局部单位；最终像素绘制有整数像素量化。不能把骨骼数值精度等同于所有动画观感已经完美。没有细指骨、口型同步、布料动力学和独立转身帧。

完整排查记录和素材提示词见 `人物动作修复-v0.3.md` 与 `粗像素人物提示词-v3.txt`。
