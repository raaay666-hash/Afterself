# 六章一周目 0.5.0 / 验证与交付记录

日期：2026-09-30。Godot 4.5.1 / Windows x64。本轮范围为保留第一章并制作第二至第六章，形成可连续游玩的一周目。

## 实际交付

- `build/v5/windows/StartupPhase.exe`：嵌入资源的 Windows 程序。
- `build/StartupPhase-0.5.0-Windows-x64.zip`：程序、中文说明、两份许可证和校验清单，五个文件。
- 第二至第六章新增 30 份原件、15 项证据推论、五个章内推演、15 轮对质、四段文件调查幕间；每章三个现场，按章节复用部分底图。
- 新环境底图五张：旧街、诊所、水闸、机房、董事会。全篇共九张底图。每张生成图均已检查并复制到项目 `assets/scenes/*-v5.png`；使用内置 imagegen，无外部 API。完整提示词和保存位置见 `docs/场景提示词-v5.md`。
- 后七人补齐连贯少色像素上身，全部十二人使用既有 25 骨骼系统。首章五人的已认可上身图像未替换。
- 第一章身份/生活、第二章证人身份、第三章归档方式、第四章调水复核、第五章名册去向进入最终回应。三种公共方案与两种私人决定分开表达。
