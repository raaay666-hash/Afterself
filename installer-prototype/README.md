# AFTERSELF · 安装器界面原型

直接双击 `index.html`，或通过本地静态服务器预览。所有视觉和交互都在本地运行，不依赖 CDN。

- 窗口基准尺寸 960 × 640，窄屏按比例预览。
- 窗口外顶部可切换欢迎、安装中（72%）、安装完成。
- 默认许可协议未勾选；勾选后可播放约 18 秒的完整模拟安装。
- 高级选项支持安装路径编辑和三个默认勾选项，保存后同步安装页、完成页。
- 支持取消、关闭确认，预览最小化与恢复。
- 启动游戏、打开目录、目录选择、自动启动为明确标注的模拟动作。
- 正式许可协议没有提供，当前仅为展示位置；发行版本显示“待打包确认”，所需空间显示“待打包实测”。容量、包体大小、临时空间和剩余时间均不估报，后续以真实构建与安装测量为准。
- 若关闭创建桌面快捷方式，完成页会改为提示从安装目录打开，避免错误承诺。

背景复用 `assets/scenes/archive.png`，按游戏 320 × 180 网格采样。角色复用 `assets/characters/upperbody-pixel-final-v3.png` 中林砚的上身区域与 `scripts/pixel_skin.gd` 的少色色板，使用暗青外套、米白衣领和旧黄笔记本。搭住边框、持笔记录、带上笔记本是安装器新增界面姿势。素材副本位于 `art/`。

标题栏使用 `assets/branding/INSTALLER-ICON-SELECTED.md` 指定的图标原图，未改动母版。AFTERSELF 是用户此次确认的安装器标题；游戏内部的 StartupPhase / 启动阶段名称、存档与导出配置未改变。

文案依据 `scripts/opening_cutscene.gd` 与 `docs/开场演出设计-v0.7.md`：清晨、第七码头、07 号公寓、缺失三天的记忆、互相矛盾的记录。安装器不提前揭露城市性质或后续人物身份。

安装中的百分比明确标为“演示进度”；动态任务只模拟资源部署，不表示已经执行真实安装。建议路径 `C:\Games\Afterself` 可修改，不代表已经部署或验证可写。

字体从项目已有资源复制，Fusion Pixel Font，SIL Open Font License 1.1，协议见 `fonts/OFL.txt`。

此目录独立于 Godot 游戏，不接入现有导出或安装流程。
