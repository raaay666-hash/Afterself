# 调查体验版 0.6.0 / 验证记录

日期：2026-09-30。Windows x64 / Godot 4.5.1。

## 本轮交付

- 内置 Fusion Pixel 简体中文字体（v2026.09.25），20px 小字与 24px 正文，关闭字体抗锯齿和系统回退。中文内容覆盖检查通过；勾选符号改为字体支持的字符。
- 对话框增加行距与正文空间，按实际字体行高保证短标签完整可见；通知改为独立的两行归档条，后五章也可显示；原件加入纸张穿孔与留存印记。
- 卷宗加入全篇已知线索索引、六章摘要、24 张故事卡、证据来源与本次选择。结论可点开查看解释，再回查支持它的原件。未通关章节不展示摘要和答案；跳到第二章不被计为首章通关。
- 六项现场核验，三类操作：两项时间卡交换、两项差异标记、两项旋转线路。第四、五章线路布局不同；第四章包含无需接入的支线，第五章要求按顺序经过镜像、同步、审计。
- 新调查首次对质前核验；已有对质/结案记录不被重新阻断。错误不扣线索，部分操作与复盘顺序会保存，有提示、重置、原件回读。

## 验证结果

最终导出程序的首章与动作回归 174 项、后五章回归 223 项、新调查与卷宗检查 68 项，共 465 项通过。新增窗口检查有 32 项断言通过，用鼠标完成六个操作、故事重排、来源回查、全篇索引和标题退出返回。

字体覆盖在源项目检查全部脚本与剧情数据中的汉字；导出程序检查包内可直接读取的剧情数据。界面截图检查了对白、六种核验、原件纸张、故事卡、来源和全篇索引。没有将自动输入等同真人体验验收。

最终同一 EXE 全篇窗口检查通过：从第一章开场开始，经六项现场操作、六章结案与幕间、公共方案和私人尾声，走到一周目结束。测试通过鼠标/键盘事件操作界面，后五章测试步速加快以缩短检查；不是游玩时长测量。最终日志 final-full-story-test.log 无错误。

音频检查：七类资源加载，雨声和氛围播放，正常退出。最终正常权限检查日志无错误；沙箱导出读取系统证书产生警告，不影响离线构建。
